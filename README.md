# テロップの動画合成

既存のテロップを、PythonとFFmpegで動画に重ねます。
背景、固定テキスト、初期スコアは最初のフレームから表示されます。
選手名・大会名・Best of・ラウンド名は固定、スコアだけが指定時刻に変わります。

## 必要なもの

- Python 3.10以上（追加パッケージ不要）
- FFmpeg 6.1以上とffprobe。`drawtext` と `libx264` が使えるビルド
- 1920×1080・ピクセル縦横比1:1の動画

背景PNGと日本語フォントは同梱しています。Chrome・NodeCG・Node.jsは不要です。

## 動画を出力する

`match.json` のサンプルを、実際の選手名・大会情報・スコア変更時刻に書き換えてください。
サンプルの名前・変更時刻は入力動画の内容から取得したものではありません。

```bash
python3 scoreboard.py --input input.mp4 --config match.json --output output.mp4
```

映像エンコーダーは次の優先順位で自動選択します。

1. NVENC AV1（`av1_nvenc`）
2. NVENC HEVC（`hevc_nvenc`）
3. NVENC AVC / H.264（`h264_nvenc`）
4. x264（`libx264`）

入力と同じ解像度・フレームレートの映像を短く試し書きし、GPU・ドライバー・エンコーダーが使用できない候補は飛ばします。
選んだエンコーダーは実行時に表示します。
映像ビットレートは全候補で **20,000kbpsのCBR設定**（最小・最大も20,000kbps、VBVバッファ30,000kb）です。
NVENCはpreset p4、x264はpreset mediumで、出力のピクセル形式はyuv420pです。
音声はコピーするため、音声とMP4の管理情報の分はファイル全体のビットレートに加算されます。
20,000kbpsは映像エンコーダーの設定値で、短いクリップではVBVバッファとヘッダーの影響で実測の平均ビットレートに差が出る場合があります。
フレームレートは入力を維持します。
出力先が既にある場合はFFmpegの `Overwrite? [y/N]` で、`y` を入力すると上書き、`n` またはEnterで中止します。
入力音声がMP4に対応していない場合はFFmpegがエラーになります。

## 設定

```json
{
  "eventName": "大会名",
  "bestOf": 5,
  "round": "Losers Quarter Finals",
  "leftPlayerName": "選手A",
  "rightPlayerName": "選手B",
  "initialScore": { "left": 0, "right": 0 },
  "scoreChanges": [
    { "at": "00:02:13.500", "left": 1, "right": 0 },
    { "at": 340, "left": 1, "right": 1 }
  ]
}
```

- `eventName`: 大会名。空文字にすると「Best of 5」のように表示。
- `bestOf`: 1以上の整数。何試合制かを指定。
- `round`: 大文字に変換し、`QUARTER FINALS` を `QUARTERS` に置き換えて表示。
- `leftPlayerName` / `rightPlayerName`: 表示名。スポンサー名なども文字列に含められます。
- `initialScore`: 動画先頭の左右のスコア。
- `scoreChanges`: 変更の一覧。変更後の左右両方のスコアを指定。変更しない場合は空配列 `[]`。

`at` は元動画の先頭を0秒とする秒数、`HH:MM:SS.mmm`、または `MM:SS.mmm` です。
`MM:SS.mmm` は時間部分を0として補正します。例えば `03:31.224` は `00:03:31.224` と同じ時刻です。
ミリ秒部分は省略可能。フレームより細かい時刻は、その時刻以降の最初のフレームから反映します。
変更時刻は昇順で、同じ時刻の指定は1件にまとめてください。
スコアは非負整数で、増加・減少・0へのリセットに対応します。

## スコア切り替えの動き

例えば `at: 133.5` のときは以下の順に表示します。

1. 133.5〜133.7秒: 旧スコアをフェードアウト。
2. 133.7〜133.9秒: 新スコアをフェードイン。
3. 133.9秒以降: 新スコアを表示し続ける。

元実装のFramer Motion `easeOut`（`cubic-bezier(0, 0, 0.58, 1)`）を使います。
変わった側だけアニメーションし、同じ値を再指定してもフェードしません。
同じ側のスコア変更は0.4秒以上あけてください。左右別々の変更は0.4秒以内でも指定できます。
固定テキストは白、スコアは `#FFD87F`。右スコアのみRegular、それ以外はMediumです。

## 短い区間で確認する

最初の3秒を出力:

```bash
python3 scoreboard.py --input input.mp4 --config match.json --output previews/start.mp4 --duration 3
```

最初のスコア変更を含む132〜136秒を出力:

```bash
python3 scoreboard.py --input input.mp4 --config match.json --output previews/change.mp4 --start 00:02:12 --duration 4
```

出力先のフォルダは先に作成してください。`--start` と `--duration` も秒数、`HH:MM:SS.mmm`、`MM:SS.mmm` に対応します。
切り出し時もスコア変更は元動画基準で適用されます。
変更後の区間から出力しても、その区間で表示すべきスコアを引き継ぎます。
`--duration` を省略すると動画末尾まで出力します。

音声は再エンコードせずコピーするため、切り出し開始・終了位置には音声1パケット分程度の端数が生じる場合があります。

## 再現範囲

1264×100の既存背景を動画上端の中央に配置し、既存の文字領域・文字サイズを再現しています。
ブラウザの文字描画とFFmpegの文字描画には、字間やアンチエイリアスの小さな差があります。
初回のフェード、6秒の待機、長い文字の横方向縮小、実況者、下部ロゴ、カメラ枠は含みません。
長い文字も固定サイズで描画するため、設定する名前の長さはプレビューで確認してください。

## 検証

```bash
python3 -m unittest discover -s tests -v
```

設定の検証と、合成動画の実フレームを使ったスコア切り替え・切り出し時刻・フレームレート・音声の検証を行います。
